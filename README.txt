How to upload to GitHub Pages:
1. Unzip this folder.
2. Upload the CONTENTS of the folder to your GitHub repository.
3. Make sure index.html is at the top level of the repository, not trapped inside another folder.
4. Go to Settings > Pages.
5. Select: Deploy from a branch > main > /root.
6. Save and wait a few minutes.

How to upload to Netlify:
1. Unzip this folder.
2. Drag the full unzipped folder into Netlify manual deploy.
